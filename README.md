# 海康 OSD 工具（简洁版）

只做三件事：**改 OSD 名称、看通道预览、确认效果**。不动位置，不动其他配置。

通过海康 ISAPI（HTTP Digest 认证）读写设备配置，接口自动探测（兼容 NVR 的
InputProxy 路径）。单文件、纯 Python 标准库，**无需安装任何第三方库**。

---

## 适用范围

- 海康威视录像机（NVR）及支持 ISAPI 的摄像机
- 电脑需与设备在同一局域网
- 需要 Python 3.8+（或按下方方法打包成 exe 直接运行）

## 界面说明

```
┌─ 步骤1: 录像机连接 ──────────────────────────┐  ┌─ 通道预览 ─────────────┐
│ 录像机 IP: [        ]  端口: [80]            │  │                        │
│ 用户名: [admin]      密码: [下拉可选/自填]    │  │     通道实时画面       │
│ 通道号: [        ]                          │  │                        │
│ [读取当前 OSD] [通道列表] [诊断接口]          │  │ [子码流/主码流] [停止]  │
├─ 步骤2: OSD 名称 ────────────────────────────┤  └────────────────────────┘
│ OSD 名称: [                          ]       │
│ 状态: 尚未读取                              │
│ [应用修改]                                 │
├─ 日志 ──────────────────────────────────────┤
│ 操作过程、接口使用情况、报错信息都会记在这里 │
└────────────────────────────────────────────┘
```

| 区域 | 说明 |
| --- | --- |
| 录像机 IP / 端口 | 设备的访问地址与 HTTP 端口，默认 80 |
| 用户名 / 密码 | 设备登录账号，用户名默认 `admin`；密码框可下拉选择预设，也可直接输入 |
| 通道号 | 要修改的通道编号 |
| 读取当前 OSD | 读回该通道当前名称并填入名称栏，同时右侧自动显示该通道画面 |
| 通道列表 | 从录像机读取全部通道的通道号与名称，用于核对通道号填得对不对 |
| 诊断接口 | 逐个探测各候选接口是否可用，定位读取失败的原因 |
| OSD 名称 | 改好后的新名称；只校验不能为空，不限制格式 |
| 应用修改 | 下发新名称，成功后右侧画面自动重新显示，可直接核对效果 |
| 日志 | 记录每步操作、实际使用的接口、报错原文 |

## 使用步骤

1. 填好录像机 IP、端口、用户名、密码、通道号，点「读取当前 OSD」。
   名称栏会自动填入设备上当前的名字，右侧出现该通道画面。
2. 在「OSD 名称」栏改成新名字，点「应用修改」。
3. 成功后右侧画面自动刷新，肉眼核对新名称已经叠加在画面上。

## 工作原理

1. **读回再下发**：应用修改时，工具先读回设备原配置，只替换名称字段后
   整体下发，名称位置、时间位置等其余配置原样保留。
2. **名称同步**：如果设备里「通道名称」和「画面叠加里的名称」不一致
   （日志会提示），应用时会把两者一并同步成新名称。
3. **接口自动探测**：不同型号 / 固件的接口路径可能不同，工具会自动探测
   候选路径（兼容 NVR 的 InputProxy 路径），读取成功后日志会打印实际
   使用的接口，形如 `使用接口: 通道名称接口 / OSD 叠加接口`。
4. **预览**：优先播放 MJPEG 视频流（httpPreview 接口）；设备不支持时
   自动降级为连续抓图；可在预览区切换子码流 / 主码流或停止。
   JPEG 解码零依赖（Windows 用系统 GDI+，兜底纯 Python 解码器），
   预览画面缩放上限 512×384。HTTP 超时 10 秒。

## 常见问题

- **连不上 / 读取失败**：先核对 IP、端口、用户名、密码，以及电脑与设备
  是否在同一局域网；再点「诊断接口」，看日志里哪条接口不通，
  把日志发给开发者分析。
- **预览只有抓图、没有视频**：说明设备该码流不支持 MJPEG 输出，属正常；
  可切换子码流 / 主码流再试一次。
- **应用修改失败**：程序目录会保存 `PUT失败_*.xml`（仅含设备配置内容，
  用于排查），设备原配置不会因此被改动；可凭该文件和日志进一步分析。
- **输入有误弹窗**：IP、端口、通道号没填或格式不对，补全后重试。
- **真 RTSP 视频播不了**：标准库没有 H.264 解码能力，本工具不支持，
  预览只走 MJPEG 视频流或抓图。

## 打包成 exe（Windows）

```bash
pyinstaller --onefile --noconsole --name 海康OSD简洁版 hikvision_osd_tool_lite.py
```

成品在 `dist/` 目录下，拷到任何 Windows 电脑双击即可用，无需装 Python。

## 隐私说明

- 本开源版本**不含任何真实密码**：密码框的预设列表为空，如需预设请在
  源码密码框处的注释指引下自行添加。
- 密码仅用于与设备建立本次连接，不写入任何文件。
- 下发失败时保存的 `PUT失败_*.xml` 仅含设备配置内容，不含密码，
  不需要时可直接删除。
